# ELF DUCK CRM

## Вход

- **Prod:** `https://elfduck-crm.telebots.site` (или ваш `CRM_ALLOWED_ORIGINS` / порт `3002` локально).
- Пароль задаётся в `.env` как `CRM_ADMIN_PASSWORD`.
- После входа откройте **Продажи → Клиенты** — кнопка **«CSV база»** скачивает полную выгрузку пользователей.

Локально: `http://localhost:3002`, API — `VITE_CRM_API_URL` (обычно `http://localhost:3000`).

## Черновики без роутов

В `src/pages/` лежат **Settings.jsx**, **Employees.jsx**, **ActionHistory.jsx** — UI на `mockData`, в меню и `App.jsx` не подключены. Рабочие разделы: дашборд, заказы, клиенты, лиды, **остатки**, партнёры, кэшбэк, push, товары, точки. Черновики можно подключить позже или удалить, если функционал не планируется.
